지갑 준비

DX는 이 브라우저 안의 전용 지갑으로 직접 거래합니다. 소액만 넣어 쓰는 지갑을 권장합니다.

기존 지갑 가져오기

확장프로그램 잠금 비밀번호 선택

Phantom, MetaMask의 잠금 비밀번호와 같은 기능입니다. 지갑 자체의 비밀번호가 아니라, 이 PC에서 DX Trader를 여는 비밀번호입니다.
  • 브라우저를 다시 열거나 60분 동안 쓰지 않으면 DX Trader가 잠깁니다. 잠긴 동안에는 DX 버튼으로 거래할 수 없습니다.
  • 이 PC에 저장되는 private key를 이 비밀번호로 암호화합니다.
  • 비밀번호는 어디에도 전송되지 않아 찾을 수 없습니다. 잊으면 private key로 지갑을 다시 가져와야 합니다.
잠금 없이 쓰면 팝업과 DX 버튼이 바로 동작하지만, key가 이 PC의 Chrome 프로필에 암호화 없이 저장됩니다. 나중에 설정에서 켤 수 있습니다.

private key 백업

아래 key를 안전한 곳에 저장하세요. 이 key만 있으면 다른 지갑(Phantom 등)에서도 같은 지갑을 열 수 있고, 잃어버리면 자금을 되찾을 수 없습니다.
